# Desmistificando o ROI — Landing page

Landing page do curso **Desmistificando o ROI** (Next Level Business Academy), desenvolvida pela Flyus.

Site estático: `index.html`, `styles.css`, `main.js` e `assets/`. Publicado via GitHub Pages para aprovação do cliente.

- Link de checkout: definir `CHECKOUT_URL` no início de `main.js`.
- Ao publicar uma atualização, aumente o `?v=` dos links de CSS/JS em `index.html`.
- A tag `<meta name="robots" content="noindex">` mantém a prévia fora do Google; remova-a na publicação final.
